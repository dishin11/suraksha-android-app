# Contributing to Suraksha

Thank you for your interest in improving Suraksha.

## Before contributing

1. Check the existing issues and pull requests to avoid duplicate work.
2. Describe the problem or improvement you want to make.
3. For substantial changes, open an issue first so the approach can be discussed.

## Making changes

1. Create a branch for your change.
2. Keep changes focused and use clear commit messages.
3. Add or update documentation when behavior or setup instructions change.
4. Test the affected flows on an Android device or emulator where possible.
5. Include the Android version, device/emulator, steps to reproduce, and results when reporting a bug.

## Pull requests

A useful pull request includes:
- A short explanation of the change and why it is needed
- Screenshots or a short recording for UI changes, where useful
- Testing performed and any tests not performed
- Known limitations or follow-up work

Please do not include passwords, API keys, personal data, or production user information in commits or screenshots.

## Current project status

The repository currently contains project documentation and is being prepared for further source-code contributions. The compiled APK is not a substitute for the original Android source code.
