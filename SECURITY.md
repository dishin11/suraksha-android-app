# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Suraksha, please do not publish exploit details or sensitive user information in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner privately through a verified contact channel listed on the owner's GitHub profile.

Please include:
- A clear description of the issue
- Steps to reproduce it
- The affected app version, device, and Android version
- The potential impact
- Any suggested mitigation, if known

Do not include real payment credentials, OTPs, private keys, or personal financial information in a report.

## Scope and response

This repository does not yet publish a supported-version matrix or response-time commitment. Reports will be reviewed as the maintainer is able.
